# 📩 Newsletter Signup Modal

A responsive **Newsletter Signup Modal** built using HTML5, CSS3, and JavaScript. The popup automatically appears after a short delay and allows users to enter their email address with basic form validation.

## 🚀 Features

- ⏱️ Automatic popup after 3 seconds
- 📧 Email input with validation
- ❌ Close button to dismiss the modal
- 🖱️ Close modal by clicking the overlay
- ⌨️ Escape key support
- 📱 Responsive design for mobile and desktop
- ✅ Success message after valid submission
- 🎨 Modern UI with smooth animations
- 🔒 Prevents the popup from reopening after dismissal during the same page session

## 🛠️ Technologies Used

- HTML5 – Page structure
- CSS3 – Styling, responsive layout, and animations
- JavaScript – Modal behavior, timer, and form validation

## ⚙️ Installation and Setup

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Make sure all three files (`index.html`, `style.css`, and `script.js`) are in the same folder.

4. Open `index.html` in your browser, or use the Live Server extension in VS Code.

5. Wait 3 seconds to see the popup.

## 💡 How It Works

1. The JavaScript `setTimeout()` function triggers the modal after 3 seconds.
2. Users can open the modal manually using the Subscribe Now button.
3. The email address is checked before submission.
4. Users can close the popup using the close button, overlay, or Escape key.
5. A success message appears after valid submission.
